# Flutter Counter Navigation App

A beginner-friendly Flutter project demonstrating:

- `StatefulWidget` & `setState()`
- `Navigator.push()` / `Navigator.pop()` for screen transitions
- `BottomNavigationBar` with Home and About tabs
- `TabBar` & `TabBarView` inside the Home screen
- Lifecycle methods: `initState()` and `dispose()`

## Getting Started

```bash
flutter pub get
flutter run
```
